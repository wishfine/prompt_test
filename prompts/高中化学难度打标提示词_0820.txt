## 二、还原整题实际作答任务

predicted_accuracy 表示本题在统一难度标尺上的整题难度等效正确率，不是单个选项的命中概率，也不是把彼此独立的基础判断按全对联合概率累计后的数值。

1. 选择题的四个选项不能当成四道独立小题后相乘概率。应评估完成整道选择题的典型作答成功率。
2. 多小问若彼此独立，不累加为一条虚假的连续推理链；要判断完成整题时必须分别完成哪些化学判断、这些判断能否由同一规则合并完成，以及它们是否形成真实的串行、联合或非基础累计负担。
3. 多小问可以不直接复用前问答案，但仍共享同一复杂的物质—反应—装置—参数网络。不得用“答案不复用”推出“不共享模型”。
4. 解析中的机械计算、重复代入、抄写方程式、逐项阅读不单独计为新的化学决策。

### 必须分别完成的化学判断

先还原普通考生为完整答对本题必须完成哪些化学判断；再判断这些判断能否由同一条规则、共同条件、共同守恒关系或同一模型合并完成。这里不按选项数量、知识点数量、机械计算次数或最终答案数量机械计数，也不在本节估分或定档。

- 这里的“一条规则”是可直接执行的同一化学判断方法：更换对象后，仍按同一种教材关系或同一套固定核查方法直接得到同类结论，才是同一规则的平行应用。不要求使用完全相同的句式，也不要求不同对象具有相同物质名称；关键是考生不必另选新的决定性性质、反应条件、守恒关系、实验原理或输出规范。
- “物质性质与用途判断”“化学键与物质分类判断”“常见反应规律判断”“元素性质判断”“实验操作正误判断”等只是专题或题型名称，不是具体化学判据，不能用来证明多个判断可以合并。
- 只有题目条件、所需化学关系和判断标准均相同，且一个判断结论不影响另一个判断时，同一教材规则或同一显性模型下的平行替换才可以作为同一类判断。
- 不同规则、不同信息来源、不同输出规范，或虽属同一专题但仍须分别确定反应是否发生、物种状态、适用条件、守恒关系、书写规范或定量关系的判断，只有确实都必须独立完成才能锁定答案时，才分别保留。
- 一条明确公式的直接代入、一次单位换算或一次显性比例计算本身只是一项判断；重复代入同一公式、同一规则下换数值或换对象，均不增加判断类型。
- 多小问以必须给出的不同答案和实际判断依据为单位；后问必须以前问结论、同一中间体、同一状态网络或共同参数为输入时，应视为递进作答链，而不是若干并列任务。

#### 化学判断的合并边界

- 同一专题不一定只包含一类判断。例如化学用语、电子式、离子方程式、原电池判断或平衡表达式的“正确/不正确”题，需看是否分别核查类别、书写规范、守恒、反应条件、电子转移或结构对应关系；不能只因属于同一专题而合并。
- 若四个选项只是在同一个判据下做平行替换，例如只判断“是否属于某类物质”且不需要额外条件、书写规范或第二个规律，应合并为一类判断。
- 若四个选项涉及不同规则，仍须检查这些规则能否由共同条件、共同守恒关系或同一模型合并；不能合并时才分别保留。即使存在多类直接、显性、互不依赖的基础判断，也不能仅据此降低正确率。
- 合并前检查能否用同一种可执行判断方法覆盖所有准备合并的任务。若只需替换物质、数值或对象，而所用教材关系、核查顺序和结论类型不变，可以合并；若必须改用另一种决定性性质、反应条件、守恒关系、书写规范或实验原理，则不能合并。不得用专题名称代替这项检查，但也不得为了写出不同措辞而把同一基础方法机械拆开。
- 单选题不因有四个选项就自动产生四类判断；应按正常锁定答案所不可省略的判断确定。若一个选项可由唯一共同判据直接锁定，其他干扰项不因被逐项阅读而自动新增类型；若锁定答案确实必须分别核查不同判据，则按实际判据数量记录。

### 答案依赖与共享模型

- 答案依赖：后一问必须直接使用前一问的数值、物质或结论。
- 共享模型：各问答案即使可以分别写出，仍共同依赖同一物质流、装置、反应网络、状态参数或证据链。
- 若各选项或小问只分别调用通用教材结论，彼此不共享题目特有信息，则既没有答案依赖，也没有模型依赖。
- 强依赖：后一阶段若不知道前一阶段推导出的关系、状态、参数或中间体，便无法独立建模。工艺流程、连续实验和多模型定量题中出现这种情况时，不得拆成若干独立常规任务。
- 若后一阶段所需输入已由题干直接给定，而不是必须由前一阶段推导得到，则不构成答案依赖；它仍可能构成共享模型。

### 完整作答稳定性

完整作答稳定性只评价实际化学结构带来的完成风险，不把多个彼此独立、直接显性的基础核查当作联合概率累计降分。若多个必要判断共享同一反应体系、实验装置、流程、参数或证据链，前一结论是后一作答前提，或多个本身具有非直接结构负担的输出共同构成整题任务，必须评价入口判断错误的传播和真实累计负担；不能仅因局部模型属于课内常规而高估整题正确率。

## 三、将作答任务记录为 features

本节只将第二节还原出的事实记录为 fields，不直接估分或定档。

### 作答任务与关系的字段对应

- 所有必要判断均能用同一种可执行化学判断方法完成，且只需替换对象或数值、不需另选决定性关系时，required_task_breadth 填“单一规则任务”。reason 应说明实际使用的教材关系或固定核查方法；专题名称、题型名称或“都属于性质判断”不能单独证明可以合并。
- 完整答题时必须独立完成2—3类不能合并的判断时，required_task_breadth 填“2-3个异质必要任务”。例如“判断反应是否发生+判断过量后的粒子”“核验书写规范+核验守恒”“读取实验现象+判断因果结论”。
- 完整答题时必须独立完成4类及以上不能合并的判断时，required_task_breadth 填“4个及以上异质必要任务”。例如需要分别判断反应是否发生、过量后的主要粒子、离子方程式书写、守恒关系和实验结论；每类必须使用不同条件、化学关系、信息来源或输出规范，不能只是四个选项换物质或换数值。该值只说明覆盖范围，不自动降低正确率或进入更高档；若这些判断均可直接、显性、独立完成，它也不能与其他“独立”字段合用来跨越85边界。
- 多个小问或阶段中，前一阶段推导出的结论、同一中间体、状态网络或共同参数是后一阶段必要输入时，required_task_breadth 优先填“多问递进任务链”，而不是“4个及以上异质必要任务”。
- 后一问必须直接使用前一问的数值、物质或结论时，subquestion_dependency 填“后问依赖前问”；有多问但答案互不使用时填“相互独立”；没有多问时填“无多问”。
- 各问共同依赖同一题目特有的物质流、装置、反应网络、状态参数或证据链时，shared_model_across_subquestions 填 true；若只分别调用通用教材结论，不共享题目特有信息，则填 false。
- 后一阶段必须使用前一阶段推导出的关系、状态、参数或中间体才能独立建模时，reaction_relation 填“前后反应强依赖”，process_structure 填“多阶段强依赖”；若中间体和条件已由题干直接给定、各问无需使用前问结论，只按实际关系填“显性顺序衔接”或“多阶段显性流程”。

### 有效化学决策计数（对应 step_count）

step_count 记录完成整题所需的**最长串行有效化学决策链的层数**，不是全题所有判断实例的总数，也不是选项数。并列且互不以前一结论为前提的判断处于同一层；只有前一结论改变后一判断所需的反应、物种、条件、关系或计算时，才进入下一层。填写前，必须按真实作答顺序列出“前一步结论→下一步要确定什么”的链条，再据此计数；不要先按题型印象填写步数。

每一层都应能写成“根据本题的____，确定____”或“利用前一步确定的____，判断/计算____”。一个有效化学决策必须产生新的、作答必需的化学结论，并成为下一项判断、计算或操作的前提；主作答链的最后一个决策可以直接得出答案。若不能写成这样的具体化学动作，就不计为有效化学决策。不要由知识点数、物质数、方程式行数、选项数或计算书写量反推步数。

四个选项分别直接套用不同教材规则时，可以属于同一并列决策层：required_task_breadth 记录其判断类型，step_count 不得按四个选项累计。填写“单一规则任务”或“1—2步”前，必须逐项检查是否遗漏了反应过程、物种状态、条件范围、现象因果、结构限制或定量关系的确定；存在任一必要确定动作时，不得仅以“模型熟悉”“最终答案只有一个”压缩为一步。

只有引入新的化学决策时才计入有效化学决策数：
- 确定或更换反应模型、平衡模型、实验模型；
- 建立新的物质状态、反应阶段或中间体关系；
- 引入新的独立规律，如守恒、平衡、结构性质、电化学关系；
- 由流程图、图谱、实验现象或数据反推隐含信息；
- 建立一个独立方程或用新约束筛选化学可行解；
- 验证过量/不足、终点、有效区间、分类或方案可行性。

不计入有效化学决策数：同一规则下换对象、换数值或平行核查选项，同一比例关系的中间量、纯算术、重复换算、重复配平、只是把结论换一种说法。并列但不可合并的判断类型由 required_task_breadth 记录，不能重复计入 step_count 的连续决策链。

### 知识点计数（对应 knowledge_points、knowledge_count、knowledge_scope）

- 只统计解题时需要独立调用的教材规律、化学模型或实验原则。
- 同一规律的同义表述、公式与变形、同一守恒关系的重复使用，只计一个知识点。
- 只在题干中出现但不参与解题的名词不计入。
- “化学实验”主要表示任务形式和实验方法，不得仅因一道内容题使用实验情境，就把 knowledge_scope 填为跨模块综合。

### 核心物质计数（对应 substance_count、substance_relation）

- 只统计需要识别性质、建立转化关系、进行检验或参与定量约束的核心物质。
- 未参与推理的溶剂、旁观离子、背景材料不计；催化剂若只作为明示条件也不单独计。
- 同一物质在不同状态、浓度或阶段反复出现，仍计一种；若其不同存在形态需要分别建模，可作为不同化学粒子计数。
- 题干罗列物质多不等于 substance_count 高；必须看它们是否真正进入作答链。

### 有效反应节点计数（对应 reaction_count、reaction_relation、competing_reaction、process_structure）

- 按需要独立确定反应条件、方向、产物或计量关系的有效反应节点计数，不按题干中化学方程式的行数计数。
- 同一可逆反应的正、逆方向通常算一个反应节点。
- 同一反应的分子方程式、离子方程式和重复使用不重复计数。
- 多小问重复使用同一反应，只计一个反应节点；竞争分支只在需要实际比较或筛选时才分别计数。

## 四、features 合法取值与关键字段说明

knowledge_L1：化学基本概念 / 元素化学 / 化学反应原理 / 有机化学 / 化学实验（数组）

knowledge_L2 到 knowledge_L1 的固定映射：

calculation_model：无定量计算 / 常规化学计量 / 多步化学计量 / 浓度或气体综合 / 平衡常数或Ka/Kb/Ksp / 多模型定量耦合
equation_structure：无方程 / 单方程 / 2-3个方程联立 / 4个以上方程或不等式组
calculation_complexity：直接判断 / 简单计算 / 多步计算 / 多方程联立 / 参数或范围计算
parameter_operation：无参数 / 单参数 / 双参数 / 多参数
information_carrier：纯文字 / 单一图表 / 实验装置 / 工艺流程图 / 光谱或图谱 / 多载体综合
information_conversion：无信息转换 / 直接读取 / 单次关系转换 / 多源信息联合转换 / 流程或图谱反推
experiment_requirement：无 / 基础操作或读数 / 直接现象解释 / 数据归纳 / 控制变量或异常分析 / 方案设计或误差反演
route_design_requirement：无 / 已知路线补全 / 路线比较选择 / 合成路线设计 / 分离提纯方案设计 / 路线优化与可行性验证
context_type：纯化学 / 工业生产 / 实验探究 / 有机合成 / 生活环境与材料
context_load：纯包装 / 简单规律映射 / 需要信息转换 / 需要自主情境建模
error_risk：无明显易错点 / 轻微易错点 / 明显易错点 / 高易错点

### 关键字段执行标准

#### 1. substance_relation

- 单一物质：核心作答只围绕一种物质的性质或定量关系。
- 相互独立：多种物质分别判断，结论互不提供条件。
- 同一反应体系：多种物质参与同一个显性反应或平衡，路径清晰。
- 前后转化依赖：前一物质或反应结果是后一阶段的必要条件。
- 组成—性质—反应网络：需要在多种物质的组成、结构、性质和多条转化之间反复反推，不能用单一顺序链完成。

#### 2. reaction_relation 与 process_structure

reaction_relation 只描述化学反应节点之间的关系；process_structure 描述整个作答流程，包括反应、分离、检验、计算和方案验证等阶段。

- 显性顺序衔接：反应前后相连，但中间产物和条件均明确。
- 前后反应强依赖：必须先推出中间产物、数量或条件，才能建立后续反应。
- 多路径反应网络：存在多个可能分支、竞争路径或需用证据排除的转化。
- 多阶段显性流程不等于多阶段强依赖；只有前一阶段的隐含结论、定量结果或条件筛选真正决定后一阶段时，才填“多阶段强依赖”。
- 对有机合成路线，若后问需要以前面反推的结构、同分异构筛选结果或中间体官能团关系为条件，路线图箭头显性不等于作答依赖弱，应填“前后反应强依赖”或“多阶段强依赖”。

#### 3. model_explicitness 与 model_relation

- 模型完全显性：题干已直接给出本题实际反应、物种状态、核心关系和使用路径；考生只需把已给出的关系用于当前判断或计算，不必先判断“本题实际发生什么、处于什么状态或各量满足何种关系”。
- 半隐含模型：课内模型已知，但必须先利用一个题目载体确定本题实际关系。例如由一张曲线确定反应方向或组成、由装置和总反应确定电极反应、由流程节点和条件确定试剂作用；确定后才可套用标准模型。
- 隐含模型：核心反应、平衡、实验关系或有效条件未明示，必须把两个及以上现象、数据、条件或图表信息合起来还原后才能作答。
- 需要自主建模：题目未提供可直接套用的完整关系，必须自行构造未知物质、反应网络、多平衡、定量关系或方案可行性的整体模型。
- 同一模型多状态指同一守恒或平衡模型在不同条件下的使用；模型切换指需要从一种独立关系切换到另一种；多模型耦合指两种以上模型的结果互为条件。

#### 4. information_conversion、representation_conversion 与 calculation_complexity

三个字段分别回答三个不同问题：information_conversion 只问“题目载体中的信息是否需要转成新的化学关系”；representation_conversion 只问“是否需要在化学表征之间转换”；calculation_complexity 只问“数量关系需要经过几层定量运算”。不得用其中一个字段代替另外两个。

**information_conversion：**
- 无信息转换：题目只提供文字条件，且不需从图、表、装置、流程、谱图、现象或数据中提取信息。
- 直接读取：图、表、装置或流程直接给出的数值、名称、步骤或现象本身就是答案；读取后不需确定新的化学关系。
- 单次关系转换：必须由一个载体先确定一条本题特有的化学关系，再作答。例如曲线→反应方向或物种组成，装置+总反应→电极反应，流程节点+条件→试剂作用，现象→离子或反应关系。
- 多源信息联合转换：必须把两个及以上数据、图表、现象、条件或载体信息合起来，才能确定化学关系。
- 流程或图谱反推：必须依据多节点流程、谱图特征或多个图像信息反推出物种、反应路径、结构、条件或有效区间。

**representation_conversion：**
- 无转换：不需在宏观现象、微观粒子、结构式、化学方程式、图像中的化学表征之间转换。
- 一次常规转换：只完成一次直接表征对应，例如结构式→官能团，实验现象→离子方程式。
- 多次同类转换：需对多个对象重复完成同一类表征对应，例如多个现象分别对应离子或反应。
- 多表征连续转换：必须连续跨越两种及以上化学表征，例如现象→粒子关系→方程式，或晶胞图→粒子位置→空间/定量结论。
- 逆向表征转换：由产物、曲线、性质或结果反推反应、结构、条件或过程。

图、表、装置或流程本身不自动构成 representation_conversion；它们首先按 information_conversion 判断。反过来，定性信息反推不应因“有两步推理”而虚填 calculation_complexity。

**calculation_complexity：**
- 直接判断：不涉及数量关系计算，只作定性判断。
- 简单计算：题干已给出所需定量关系和全部量，只需一次代入、比例、单位换算或直接读数计算。
- 多步计算：必须先由题目信息得到必要的数量关系，再依次进行守恒、计量、浓度、平衡或后续计算；例如残留率→产物质量→元素守恒→化学式。
- 多方程联立：必须同时使用两个及以上独立方程、守恒关系或等式组求解。
- 参数或范围计算：必须求出临界条件、参数关系、可行范围或分类区间。

#### 5. evidence_relation

- 多证据独立：多条证据各自回答不同任务，互不提供前置条件。
- 证据链相互支持：一条证据缩小范围，另一条证据继续确认结构、物质或反应路径。
- 证据冲突需排除：存在表面相符但不能同时成立的结论，必须利用条件、误差、副反应或物理状态排除。

#### 6. critical_condition、classification_discussion 与 constraint_structure

- 显性给出临界：分界条件已在题干或解析中明确给出，只需直接使用。
- 需要推导过量不足边界：必须先建立计量或反应先后关系，才能确定哪个物质过量或剩余。
- 隐含终点或有效区间：终点、有效解或可行区间未直接给出，需要利用化学条件筛选。
- classification_discussion 只统计解题必须分别建模并产生不同结论的有效分类；不统计只是逐项阅读选项。
- 多约束相互独立指各约束分别用于不同小问；它只记录任务事实，不等于联合约束，也不能单独支持低于85。多约束联合筛选指必须同时满足浓度、平衡、安全、纯度、收率或装置等多类条件才能得到结论。

#### 7. experiment_requirement 与 route_design_requirement

- 基础操作、直接现象解释和常规数据归纳属于标准实验任务，不等于方案设计。
- 只有需要自主选择器材、设置对照、控制干扰、根据误差方向反演或验证方案可行性时，才填“方案设计或误差反演”。
- 已知路线补全是按给定框架填中间体或条件；合成路线设计要求自主选择反应顺序和官能团转化；路线优化与可行性验证还需比较收率、原子经济性、条件、副反应或工艺约束。
- 分离提纯方案只在需要根据溶解度、沸点、分配、化学转化或杂质性质自主组合操作时，才填“分离提纯方案设计”。

#### 8. 字段间一致性自检

输出前必须检查：
- reaction_count="0-1个" 时，reaction_relation 通常不得为“前后反应强依赖”或“多路径反应网络”。
- substance_count="1种" 时，substance_relation 应为“单一物质”。
- information_carrier="纯文字" 时，information_conversion 不得为“流程或图谱反推”。
- experiment_requirement="无" 且 route_design_requirement="无" 时，reason 不得声称存在实验或路线设计。
- classification_discussion="无" 时，reason 不得声称需要复杂分类。
- subquestion_dependency="无多问" 时，shared_model_across_subquestions 必须为 false。
- required_task_breadth="单一规则任务" 时，reason 不得声称存在多个不可合并的必要判断、多个异质输出或递进链；required_task_breadth="多问递进任务链" 时，subquestion_dependency 或 shared_model_across_subquestions 必须体现实际依赖。
- required_task_breadth="单一规则任务" 时，reason 应具体说明实际使用的教材关系或固定核查方法，以及为什么更换对象后仍可直接沿用；不强制使用固定句式。若只能写出“物质性质”“化学键与分类”“常见反应”“元素性质”“实验判断”等宽泛类别，说明尚未证明可以合并。填写“2-3个异质必要任务”或“4个及以上异质必要任务”时，reason 应列出实际不同的决定性判据，不得只列选项字母、知识点名称或物质名称。
- 各选项或小问若相互独立，不得把 reaction_relation、evidence_relation 或 model_relation 填成强耦合值。
- features 必须优先反映题目事实，不得为了让 predicted_accuracy 看起来合理而反向修改。

## 五、features 真实性与一致性检查

1. 多物质只在需要分别建模并互相约束时才是强耦合；并列物质识别不是。
2. 多反应只在前后产物、反应条件或平衡强依赖时才是反应链；并列配平不是。
3. competing_reaction 只在实际解题需要在竞争反应、副反应或有效产物中筛选时填高阶值。
4. “过量”“不足”“终点”“范围”等词出现不等于隐含临界，必须确实需要推导边界或筛选有效区间。
5. 一个难点若同时表现为“竞争反应+过量临界+2类讨论”，应分别如实填写对应 features；但这些表现若来自同一个化学决策节点，不得在 reason 中将其描述为多个彼此独立的难度来源。
6. 仅出现工艺流程图、光谱图、实验装置或有机合成路线时，information_carrier 应如实填写，但不得因此自动提高 information_conversion、reasoning_chain、constraint_structure 或 route_design_requirement。只有实际需要多源联合反推或方案约束验证时，才填写对应的高阶枚举值。
7. 普通守恒、常规平衡、单次单位换算和标准实验操作，应按实际复杂度填写，不得因其名称自动提高 step_count、model_relation、calculation_complexity 或 experiment_requirement。
8. features 的事实真实性优先于“看起来与正确率匹配”。不得为了解释低正确率而人为抬高 features。
9. features 必须与真实主作答链一致。若作答需要“先确定实际反应、物种状态、适用条件或结构关系，再据此完成另一判断或计算”，不得同时填写 step_count="1-2步"、model_explicitness="模型完全显性"、reasoning_chain="直接套用"以及无信息/表征转换；应按题目实际分别修正有关字段。若由现象、曲线、结构、流程或数据得到新的化学关系，相关转换字段不得全部填“无转换”；若先建立定量关系再求值，calculation_complexity 不得填“直接判断”。反过来，多个选项的并列核查不是串行决策链，不得仅因选项数提高 step_count。

## 六、根据任务与 features 估计原始正确率

原始正确率只基于已如实填写的全部相关 features 综合估计，不由某一个 feature、任务数或题型直接决定。同一真实作答负担即使体现在多个字段中，也只能按一次实际完成难度估分；不得把同一难点换用多个名称后重复压低 predicted_accuracy，也不得把多个直接、显性、彼此独立的基础判断隐式相乘后压过主边界。

### 给分前的固定核对顺序

1. 先还原完整作答任务，并将全部题目事实填写为 features：包括有效化学决策及其数量、反应和物质关系、条件与约束、信息转换、计算、实验/路线、依赖和共享模型。实际反应、状态、条件、因果或定量关系若影响作答，必须反映在相应 feature 中。此时不选分数。
2. features 填完后，按以下五组证据作一次整体核对：

   - 化学范围：知识模块、核心物质、反应节点、跨模块关系；
   - 作答任务：有效化学决策、必要判断类型、评分输出、任务是否可合并；
   - 关系结构：反应/流程关系、模型显性度与关系、条件约束、答案依赖和共享模型；
   - 信息与定量：信息载体及转换、化学表征转换、证据关系、计算模型与复杂度；
   - 完整完成风险：实验/路线任务、情境任务、关键错误是否影响后续作答；以及多个本身非直接的必要输出是否形成实际累计负担。

   五组只是同一题目 features 的不同观察面，不得按组数或字段数机械累计；同一化学关系在多个字段中出现时，只按一次真实作答负担评价。
3. 按顺序比较四条边界，不另设抽象的“综合程度”规则：

   - **88边界：** 是否只有同一教材规则或完全显性的模型，考生不需额外基础核查？若是，比较88及以上；否则继续比较85。
   - **85边界：** 所有必要判断是否都能直接开始，或者每项最多只需一次化学确定动作且该动作直接得到当前答案？若是，即使有多个并列基础核查，仍比较85及以上。若取得答案前必须先确定本题实际的反应、物种状态、适用条件、结构限制或定量关系，再利用该结果完成另一化学判断或计算；或者必须联合多个条件才能确定该关系，则进入85以下。
   - **58边界：** 上述常规综合是否仍围绕一个局部体系、有限约束和可依次完成的关系链展开？若是，比较58—85。若存在明确的体系化信息反推、较难联合定量、复杂实验/误差/方案评价，或多个本身非直接的任务共同形成明显累计负担，则继续比较38。
   - **38边界：** 检查信息反推、联合条件、复杂定量、反应或模型复杂化、高阶实验或路线五类可观察证据。任一类若由相互支持的 features 共同成立并构成主作答负担，或多个中等结构围绕同一体系显著降低完成稳定性，应比较38—58；只有两个及以上高阶阶段强依赖、前一阶段限制后一阶段建模时，才继续比较38以下。

   不得只用“模型完全显性”“直接判断”“简单计算”或任何单一 feature 作为保留在某一区间的理由；也不得只因一个高阶 feature 自动升档。选项多、知识点多、易错点或机械书写量也不单独跨越任何边界。
4. 确定进入某一区间后，必须按照该档“区间内判分”说明，并结合该档的核心状态、典型结构和相邻边界条件确定上、中、下位置。完成整体比较后才选择 predicted_accuracy，不得先选取常用整数、区间端点或其他习惯分数，再回头用 features 和 reason 凑解释。
5. reason 必须写出主作答链的有效化学决策及其数量，并说明与相邻边界的实际区别：88及以上须说明覆盖全部必要判断的具体教材关系或固定核查方法及不存在额外必要判断，但不要求固定句式；85—88说明各项不同基础判据，或一次化学确定动作如何直接得到当前答案；58—85说明“先根据什么确定何种实际反应、状态、条件、结构或定量关系→再利用该结果完成什么判断或计算”，或说明哪些条件必须联合建立该关系；38—58应指出五类拔高结构证据中实际成立的类别、对应 features 及其怎样构成主作答负担；低于38说明阶段 A→阶段 B，以及后一阶段为何不能脱离前一阶段独立建模。并列选项核查不得被写成多步链，不得只列一个 feature，也不得用“课内常规”或宽泛专题名称替代具体判据和整体说明。

请使用以下统一的正确率参考尺度校准 predicted_accuracy。各区间描述的是目标考生面对相应作答结构的典型完成稳定性，不是并列基础任务的真实联合全对概率。第一阶段固定使用 88 / 85 / 58 / 38 四条边界，不得使用 75 / 55 / 35 或其他旧标尺。

### 88 分边界

#### 核心状态

- **题目性质：** 送分题。
- **必要判断：** 整题只需一种必要化学判断类型，即只调用同一条教材规则或同一个完全显性的模型。
- **作答链：** 通常有1—2个有效化学决策；即使包括“识别对象→直接应用同一规则”两个动作，只要没有独立的条件筛选、关系转换或第二类判断，仍属于本区间。
- **作答本质：** 题干已经给出作答所需的对象、条件和关系；考生只需识别对象并直接调用已有规则，不必先判断本题实际发生什么、处于什么状态或哪些条件成立。

#### 典型结构

- 一步规律应用。
- 关系完全显性的一步代入。
- 同一回答规则下的直接选项辨析。
- 出现化学反应、四个选项、四种物质或四个反应名称，本身不改变上述结构。

#### 区间内判分

- **靠近100：** 唯一回答规则，只有1—2个有效化学决策，模型完全显性，无表征/信息转换、实验推理或定量计算。
- **靠近88：** 仍只用同一规则，但需先识别对象或完成一次直接代入。
- **不得降档的理由：** 轻微易错点、逐项阅读选项或对象名称较多，不能单独把正确率压到88以下。
- **一致性检查：** 若 reason 已说明只有单一教材规则、模型完全显性且不存在额外必要判断，predicted_accuracy 必须不低于88；给出低于88时，reason 必须写明额外独立规则、条件筛选或额外化学判断。

#### 相邻边界

- **进入85—88：** 多个选项实际调用不同规则，或存在明显条件筛选、关系转换、简单定量或额外独立化学判断。
- **仍不进入85—88：** 四个选项、四种物质或四个反应名称并不等于四条独立规则；同一规则的平行替换仍可留在本区间。

### 85 分边界

#### 核心状态

- **题目性质：** 基础应用题。
- **核心判定：** 本区间判断的是“每项作答是否能够直接完成，或是否只有一次化学确定动作”，而不是“完整作答需要完成多少项”。只要所有必要判断均能直接从题干已给出的反应、物种、条件、关系、数据或教材规则开始完成；或者每项最多只需确定一个局部关系且该结果就是当前答案，应先在85—88范围内比较。
- **必要判断：** 可以是一个或多个不可合并的基础化学判断，也可以在同一熟悉模型中完成一次简单转换、定量、条件判断或局部关系确定。判断类型可以不止一种；关键是每项作答都不需要先确定一个化学关系，再利用该结果完成第二个不同的判断或计算，也不需要联合多个条件才能确定该关系。
- **作答链：** 各判断仍直接、显性，不形成常规综合；并列基础判断时，required_task_breadth 可以高于“单一规则任务”，而 step_count 仍可能只有1—2步，因为它们不是前后连续的化学决策链。
- **作答本质：** 考生需要分别完成基础核查，或在已给出的关系中做一次简单应用；但每一项都可直接开始，完成其中一项不需要先建立会改变另一项判断的题目特有关系。
- **85边界：** 必要判断可以有1类、2—3类或4类及以上，也可以涉及多个选项、多个填空或多个彼此不同的基础规则。只要这些判断直接、显性、彼此独立，判断数量本身不得使正确率低于85。不得把多个独立基础判断的单项成功概率显式或隐式相乘，也不得以“完整答对必须全部判断正确”“存在多个失分点”“需要逐项核验”或 required_task_breadth 较高作为跨过85边界的理由。

#### 典型结构

- 多个彼此独立的基础判断，或多个必须完整作答的异质输出。
- 一次直接、显性的条件核查、简单转换或简单定量。
- 并列基础判断不得虚构成连续链；仅因全部答对才得满分，也不能自动进入58—85比较。
- **并列基础输出：** 多个填空、多个陈述或多个选项，若每项都可依据题干已给出的反应、物质、条件、装置关系或教材规则直接完成，且完成任一项不需要先确定另一项所需的实际反应、粒子状态、条件范围或定量关系，仍属于本档。标准周期表、常规装置图或已明示反应条件的直接对应，不因出现图示自动成为半隐含模型。

#### 区间内判分

- **分数定位：** 在85—88内部，优先比较单项判断是否需要一次简单计算、单位换算、显性条件核查或直接转换，而不是按判断项数累计失分概率。所有必要关系均已明示、每项均可直接开始时，不得给出低于85的分数。
- **本档限制：** 各任务应能直接开始，或最多只有一次化学确定动作且该动作直接得到当前答案；不得形成“先确定实际反应、状态、条件、结构或定量关系→再利用该结果完成另一判断或计算”的常规综合链，也不得依赖多个条件联合建立该关系。
- **计数限制：** 不得因书写了多项答案，或逐项核验多个基础选项，就把并列输出按书写顺序累加为3—5步连续链；step_count 应记录单项作答中最长的实际串行确定过程，而 required_task_breadth 只记录并列判断的覆盖范围。
- **一致性检查：** 若 reason 已判定题目属于“基础应用”，并说明各判断直接显性且无串行确定过程，predicted_accuracy 必须为85及以上。

#### 相邻边界

- **回到88及以上：** 所有必要判断均可由同一教材规则或同一完全显性模型完成。
- **进入58—85：** 取得答案前必须先根据本题信息确定实际反应、物种状态、适用条件、现象因果、结构限制或定量关系，再利用该结果完成另一化学判断或计算；或者必须同时结合多个条件才能确定该关系。中间关系不要求被其他小问复用，但它与最终作答必须是两个不同的化学确定动作。该必要过程也可以出现在共享装置、流程、反应网络或状态参数的多个任务中。
- **仍留在85—88：** 一次简单定量、多个基础核查、半隐含表述或3—5个书写动作本身都不是充分条件。若每项作答都能直接开始，或者只需一次化学确定动作且该动作直接得到当前答案，仍按基础应用比较；若前一步确定的实际反应、状态、条件、结构或定量结果是后一步判断或计算的必要输入，就不得压缩为一次轻量应用。

### 58 分边界

#### 核心状态

- **题目性质：** 常规综合题。
- **准入条件：** 进入本区间必须满足以下至少一种情形：主作答中存在不可省略的“题目信息→确定本题实际反应、物种状态、适用条件、现象因果、结构限制或定量关系→再利用该结果完成另一判断或计算”过程；必须联合多个条件才能确定该关系；或多个任务共同依赖同一个题目特有关系、状态、参数或模型，形成串行或联合负担。
- **关系范围：** 该关系必须是针对当前题目重新确定的化学结论，不是直接调用教材事实、直接使用题干已经给出的反应或条件，也不是多个基础规则的并列核验。中间关系不要求被其他小问复用；但它必须先被确定，再用于完成当前答案中的另一个化学动作。一次化学确定动作后直接得到答案，仍可在85—88比较。
- **作答本质：** 考生不能只完成一个直接确定动作，而要先把题干中的试剂、现象、数据、结构或条件落实为“本题实际是什么关系”，再利用该关系判断或计算。例如先确定实际反应和粒子状态，再建立守恒关系并求值；或先从曲线、现象、结构中确定限制条件，再结合另一条件判断结论。
- **硬排除：** 若所有必要判断都可以直接从题干已给出的关系或教材规则独立开始，即使判断类型很多、必须全部答对、涉及多个输出或多个选项，也不得进入58—85区间，仅在88与85之间比较。

#### 典型结构

以下结构只有在已经满足本档准入条件时才属于本档；单独出现其中任一形式，不代表进入58—85。一次守恒、比例、结构、条件或简单定量应用若只包含一个化学确定动作并直接得到答案，仍按85—88比较；若必须先确定实际反应、状态或条件，再建立并使用该关系，则属于本档。

- **反应与粒子关系：** 先判断实际反应、生成物、离子/分子形态、氧化还原方向或过量后的主要粒子，再完成判断或计算。
- **条件与范围关系：** 结合酸碱性、浓度、温度、过量不足、反应先后或平衡移动，判断适用条件、成立阶段或范围限制。
- **现象、数据与结论：** 由实验现象、曲线、表格、流程节点或测量数据判断物质、反应关系、控制变量、因果关系或支持的结论，而不是直接读出答案。
- **结构与性质关系：** 由结构式、官能团、价态、电子或空间约束判断反应位点、性质、结构限制或产物可能性。
- **标准定量关系：** 先建立守恒、化学计量、浓度、平衡、电子转移或比例关系，再完成一次常规计算或判断。
- **常规实验或流程任务：** 将操作、条件、现象、目的或物质转化对应起来，判断步骤作用、实验结论或下一节点选择。
- **常见作答链：** 通常有3—5个有效化学决策，例如“根据题目条件确定反应或粒子状态→建立守恒、比例、平衡或结构关系→完成判断或计算”；也可以是较短链，但不能跳过“先确定本题实际关系”的步骤。
- **常规范围：** 所用知识和模型仍属课内标准范围，关系主要围绕一个局部体系或有限约束展开，尚未共同形成明显的拔高结构。

#### 区间内判分

- **靠近85：短链的常规综合。** 已满足本档准入条件，但串行关系较短：先确定一个本题实际反应、状态、条件、结构或定量关系，再用它完成一次标准判断或计算；或者必须联合两个及以上条件才能确定该关系。题干信息集中、后续动作标准且关系较短时更接近85。若只有一次化学确定动作且该动作直接得到答案，不属于本档，应回到85—88比较。
- **区间中部：连续的常规综合。** 必须连续完成两个或以上彼此有关的确定动作，例如“确定反应或物种状态→确定适用条件/守恒/比例→判断或计算”，或“从现象/数据/结构确定关系→结合另一条件得出结论”。信息、条件或定量关系不能跳过，但仍围绕一个局部体系，未形成明显拔高结构。
- **靠近58：下部的常规综合。** 只适用于一个局部反应、平衡、结构、实验或流程体系内的连续常规链：题目特有条件、信息/定量转换或必要关系较多，多个判断前后衔接，关键关系出错会使后续常规作答明显受影响，但各确定动作仍可依次用标准方法完成。不得仅因“有3—5步”或“分数应偏低”选择该位置。若必须围绕同一体系同时协调两类及以上非直接任务，例如信息反推与联合定量、物种状态与误差/方案判断，或复杂联合约束、较难定量建模、隐藏边界或竞争关系已成为主负担，应直接进入38—58比较，而不是留在本档。
- **具体数值：** 先确定上述哪一种主作答状态最符合本题，再依据其与85、58两侧边界的实际距离选择连续位置；不得把82、72、62或任何常用整数当作默认值。不同题只有这些实际作答状态相近时才可给出相近分数。
- **不得作为高分理由：** “课内常规”“各小问可分别写出”或“只有一个最终答案”均不能单独支持高于58。
- **不得作为低分理由：** 仅有一次标准关系判定、3—5个有效化学决策、4类及以上必要判断、半隐含模型或一次信息转换，均不自动进入38以下。

#### 相邻边界

- **回到85—88：** 题干已直接给出所需关系，考生只是在不同对象上平行调用同一教材规则。
- **进入38—58：** 复杂联合约束、较难定量建模、隐藏边界或竞争关系、复杂信息反推、较高阶实验/流程/方案评价等拔高结构实际构成主作答负担；或多个中等结构围绕同一体系共同显著降低完整完成稳定性。
- **边界解释：** 仅因知识点、选项、小问、物质或书写量增加，不足以跨越本档边界。

### 38 分边界

#### 核心状态

- **题目性质：** 较难综合题。
- **主要负担：** 整题存在较高的体系化任务或连续作答负担；局部步骤可以使用课内常规方法，但不能因“每个局部方法熟悉”而忽略整体完成风险。
- **作答本质：** 主要难点不再只是“先建立一个普通关系”，而是要围绕同一体系同时处理两个以上会互相制约的方面，例如反应条件与产物、物种状态与守恒、图表信息与定量关系、实验现象与误差来源。考生即使知道每个局部方法，也必须把它们放回同一体系协调，完整完成的稳定性明显下降。
- **累计完成负担：** 即使各小问不前后依赖，只要其中存在明确的体系化信息反推、较难联合定量、复杂实验/误差/方案评价，或多项本身非直接的异质输出共同形成明显完成负担，也可进入本区间。这里不是按小问数或任务数升档：若各项只是同一规则的平行替换，或都能直接套用显性规则，仍回到58—85比较。

#### 典型结构

- **五类拔高结构证据：** 判断是否进入本档时，使用下列五类组合，不按字段数量机械累计。同一难点在多个字段中的表现只算一个结构证据；单个高阶枚举若没有配套关系，也不自动进入本档。
  - **信息反推：** 多源信息联合转换、流程或图谱反推、多表征/逆向转换等信息处理，与多层因果、逆向筛选或证据链共同参与作答。
  - **联合条件：** 多个条件必须共同筛选同一结论，并实际涉及隐含条件、临界范围、过量不足或竞争/副反应；若条件可分别直接核查，不属于本类。
  - **复杂定量：** 多方程联立或参数/范围计算，与两个以上方程、多个参数、平衡/浓度/气体或多模型定量关系共同构成求解链。
  - **反应或模型复杂化：** 模型切换或多模型耦合，与多阶段流程、前后转化依赖、强反应链或多路径网络共同出现。
  - **高阶实验或路线：** 控制变量/异常分析、方案设计/误差反演、合成或分离路线设计，与多层因果、联合约束或证据链共同完成。
- **进入本档的口径：** 不要求五类同时成立。只要其中一类组合已经完整成立并成为整题主要瓶颈，就应进入38—58比较；若仅出现孤立字段、题型名称或载体形式，仍回到58—85比较。
- **较长连续链：** 6—8个有效化学决策由两类及以上高负担结构共同形成连续作答链。
- **短链但体系化：** 虽只有3—5个有效化学决策，但存在一个不能在孤立、显性条件下直接完成的体系化任务。
- **体系化任务的形式：** 由图表、装置、流程或实验现象反推物种、反应或定量关系后再作答；围绕同一反应或实验体系同时处理条件、现象、守恒、误差或操作目的；或多个必要输出共同受同一状态参数、反应网络或流程节点约束。
- **多项非直接输出：** 多个必须完整作答的输出分别要求不同的化学判断，例如一项完成图表/装置关系转换，另一项完成守恒或定量关系，另一项完成误差或方案评价；即使答案可分别写出，也应按整题累计负担比较。

#### 区间内判分

- **靠近58：** 体系化任务较集中、额外高负担结构较少，关键关系错误主要影响局部。
- **靠近38：** 连续作答链更长、联合约束更多、信息或定量关系更难回溯，或关键错误会影响多个必要结论。

#### 相邻边界

- **回到58—85：** 四个彼此独立且都能直接套用显性教材规则的基础判断，不因选项数或小问数进入本区间；多个异质输出中只有一项需要普通关系建立、其余均为直接基础应用时，也仍按58—85比较。
- **进入＜38：** 两个及以上高阶阶段共享同一物质流、装置、状态参数或证据网络，且前一阶段结果限制后一阶段建模，形成压轴级全链结构。

### ＜38 分边界

#### 核心状态

- **题目性质：** 压轴级全链综合题。
- **主要负担：** 通常由9个及以上有效化学决策构成全链结构；或存在两个及以上高阶阶段的强依赖，前一阶段结果限制后一阶段，并同时涉及多路径反应、多平衡耦合、复杂过量临界与分类、多约束方案验证或多源证据反演。
- **计数要求：** 有效化学决策数量仍按前述统一口径统计，不能由题干长度或书写量替代。
- **作答本质：** 题目不是一个较难任务外加若干普通任务，而是至少两个高阶阶段构成同一条主链。必须先完成阶段 A，确定其中的关系、状态、参数或中间体，阶段 B 才能开始建模；前段错误会使后段整体失效，不能拆成若干相互独立的4档任务。

#### 典型结构

- 路线反推、限制性结构筛选与自主路线设计围绕同一中间体链连续依赖，前一阶段结论缺失会使后一阶段无法完成。
- 多个高阶阶段共同依赖同一物质流、装置、状态参数或证据网络，不能拆成若干独立的较难综合任务。
- 普通工艺流程图、有机合成路线、K或Ksp计算、实验方案设计名称本身不支持低于38。

#### 区间内判分

- **靠近38：** 高阶阶段较少、依赖链较短，或存在局部补救空间。
- **靠近0：** 高阶阶段更多、前序错误传播更广，多个约束必须连续满足。

#### 相邻边界

- **回到38—58：** 高难阶段可彼此独立完成，或前一阶段结论不限制后一阶段建模。
- **不得仅因题目形式进入本档：** 工艺流程、路线、平衡计算或实验设计必须实际形成强依赖全链，才可进入本区间。

确定相邻边界后，必须依据有效决策负担、任务关系、模型与条件显性度、信息转换与运算、失分传播与整题完成五方面证据，判断题目与上下相邻边界的距离，再给出连续估计。
