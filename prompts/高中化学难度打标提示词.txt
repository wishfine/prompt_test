"""高中化学单阶段难度评级 Prompt。"""

FEATURE_EXTRACTION_PROMPT_PREFIX = r"""
你是一位资深高中化学教研专家，熟悉高中化学命题、教学、阅卷、实验评价、工业流程题、有机合成题和反应原理综合题。

你的任务是阅读题干、选项、子题、解析和必要图片，完成两件事：
1. 按指定枚举如实提取结构化 features；
2. 根据实质任务结构预测目标学生群体完成整道题的原始正确率 predicted_accuracy（0—100）。最终档位由程序按统一五档区间、程序识别的高难特征乘数和乘数后正确率计算。

这里的 predicted_accuracy 是任何程序乘数处理之前的原始预测正确率。你不得自行应用 0.85 或 0.70 乘数，也不得根据乘数反向修改 features。

================================================================================
0. 任务与输出原则
================================================================================

你需要先确定题目的实质化学任务，再按本 Prompt 的唯一枚举提取 features，随后根据完整解题任务估计乘数处理前的连续原始正确率。程序随后按独立高难特征组统一施加乘数，并把乘数后正确率映射为最终难度1—5档。

难度判断只有一条主线：
实际解题任务 → 一个原始正确率区间 → 区间内具体正确率 → 程序乘数 → 最终五档。

================================================================================
一、证据使用与任务识别
================================================================================

1. 以实际解题任务为准，不以题号、题型名称、题干长度、图片数量、化学式数量、旧 difficulty、percent_correct 或 answered_count 定档。
2. 若提供解析，优先用解析核实真实知识点、物质转化、反应条件、守恒关系、实验目的和推理链；若解析与题干冲突，以题干设问为准。解析中的重复说明、背景拓展和纯算术不得重复计步。
3. 图片缺失且文本不足时，按现有证据提取，并在 reason 中明确指出信息缺口。文字题干为空但有题干图片时必须读取图片；复合题母题文本为空但子题完整时仍要检查母题图片是否包含共享装置、流程或反应网络。
4. options 必须按题型解释：单选题和多选题缺少 options 属于输入异常；填空、主观和复合题可以没有 options，不能据此判定题目缺失或降低正确率。

### 任务识别

- 评分输出不等于实质化学任务；任务建模只用于正确估计整题完成概率，不新增 JSON 字段。
- 单选题：通常只有一个评分输出，但不一定只有一个实质化学决策。A、B、C、D 不是四个独立必答小问，不得机械累加四条推理链，也不得把各选项判断正确率相乘。
- 选项关系：若各选项只是同一规律的平行替换，按同一规则的平行应用处理；若正确作答必须分别核验不同条件、关系或知识，则将这种联合辨析负担计入整题正确率；若多个选项共享同一题目特有的反应条件、平衡体系、实验装置或充分必要条件，按共享模型下的联合辨析处理。
- 多选题：仍是一道评分任务，通常需要判断全部候选项。不得把四项正确率机械相乘；应根据不同化学决策数量、决策是否同质、错误是否由同一个误判共同导致，评估整题完成概率。若各项只是同一规则的重复应用，不得标成四个异质任务；若各项分别涉及反应原理、实验操作、结构性质和定量关系，则如实反映在相应 features 与正确率中。
- 组合题：表格式组合选项、序号组合题和“说法正确的有几个”题，先判断底层陈述数量和关系。组合编码本身不是新增化学步骤；若必须逐条验证多个独立陈述，不能只按最终一次选择计为一步。
- 多问题：只有存在多个分别要求作答的填空、小问、方程式、计算结果、实验操作或方案评价时，才考虑多个评分任务。独立小问不机械连接成长链，但其异质输出仍计入整题完成概率。
- 任务关系：subquestion_dependency 只描述后问是否使用前问答案；shared_model_across_subquestions 描述各问是否共同依赖同一反应网络、工艺流程、平衡体系、实验装置、统一参数、谱图解释框架或合成路线。答案不复用不等于不共享模型。
- 前后依赖检查：先按取得完整答案所必需的阶段列出任务。对后一阶段逐一判断：若不先确定前一阶段的反应关系、物种状态、实验结论、路线中间体、参数或边界条件，能否独立建模并得到该阶段答案？不能，则属于前后依赖；若前一关键判断出错会使多个后续阶段同时失效，则属于连续失分。共同背景但各阶段都能独立建模，只是共享模型，不是前后依赖。单选题或只有一个最终输出时也应完成这项内部检查，但不得因此虚构多个评分任务。

二、教师维度对应的 features 字段及唯一合法枚举
================================================================================

所有字段都必须输出。knowledge_L1、knowledge_L2、knowledge_points 和 chemistry_methods 为数组，shared_model_across_subquestions 为布尔值，其余字段只能选择一个完整枚举值。

### 1. 知识维度

knowledge_L1：一级模块数组，从以下值选择一个或多个：
化学基本概念与定量关系；元素化学与无机反应；化学反应原理；物质结构与性质；有机化学；化学实验与探究。

这六个一级模块用于覆盖当前题库的实际解题知识域，不按教材册次机械切分。“化学与生活、材料、能源、环境”通常是情境，不单设一级模块；其实际知识仍归入元素化学、结构性质、有机化学或反应原理。

knowledge_L2：二级模块数组，从以下值选择一个或多个：
物质组成、分类与分散系；化学用语与物质组成；物质的量与化学计量；离子反应；氧化还原反应；金属及其化合物；非金属及其化合物；无机物转化与推断；化学反应与能量；反应速率与化学平衡；水溶液中的离子平衡；电化学；原子结构与元素周期律；化学键与分子结构；晶体结构与性质；有机物结构与命名；烃及其衍生物；有机反应与合成；生物大分子与合成材料；实验基础与安全；物质制备与性质实验；检验、鉴别与分离提纯；定量实验与数据处理；实验探究与方案评价。

一级、二级对应关系：
- 化学基本概念与定量关系：物质组成、分类与分散系；化学用语与物质组成；物质的量与化学计量；离子反应；氧化还原反应。
- 元素化学与无机反应：金属及其化合物；非金属及其化合物；无机物转化与推断。
- 化学反应原理：化学反应与能量；反应速率与化学平衡；水溶液中的离子平衡；电化学。
- 物质结构与性质：原子结构与元素周期律；化学键与分子结构；晶体结构与性质。
- 有机化学：有机物结构与命名；烃及其衍生物；有机反应与合成；生物大分子与合成材料。
- 化学实验与探究：实验基础与安全；物质制备与性质实验；检验、鉴别与分离提纯；定量实验与数据处理；实验探究与方案评价。

knowledge_L1 必须与 knowledge_L2 按上述映射得到的一级模块集合完全一致，不得遗漏或额外添加模块。程序会根据 knowledge_L2 重建 knowledge_L1。知识模块只标注解题必需的化学知识，不按工业流程、生活生产等情境分类。

knowledge_points：实际完成题目所必需的具体知识点字符串数组，例如 ["弱电解质电离平衡", "盐类水解", "电荷守恒"]。不得用一级或二级模块名称代替具体知识点；不得把无需掌握即可排除的干扰项知识全部加入。
knowledge_count：1个 / 2-3个 / 4个及以上。程序按去重后的 knowledge_points 重新计算。
knowledge_scope：单知识点 / 同章节综合 / 同模块跨章节 / 跨模块综合。程序按 knowledge_L1、knowledge_L2 和 knowledge_points 重新计算；实验知识与内容知识同时出现时，只有实验原理或操作本身是必要决策，才计入跨模块。
knowledge_depth：基础概念 / 标准模型 / 深层课内模型 / 陌生迁移。

### 2. 过程维度与任务关系

step_count：1-2步 / 3-5步 / 6-8步 / 9-12步 / 12步以上。只统计得到答案所需的新增化学决策，例如确定关键物质、反应关系或条件，建立守恒/平衡/定量关系，进行图表或现象信息转换，引入独立方程、约束或分类分支，评价方案或验证临界条件。抄写、机械配平、无新决策的代数化简、重复代入、同义复述和背景说明不计步。

substance_count：1种 / 2-3种 / 4-6种 / 7种及以上。只统计解题链中必须识别、比较、转化或定量处理的物质，不机械统计干扰项和背景中出现的全部名称。
reaction_count：0个 / 1个 / 2-3个 / 4个及以上。只统计参与推理、计算或方案判断的独立反应关系；同一反应的文字式、分子方程式和离子方程式不重复计数。
reaction_relation：无反应关系 / 单一直接反应 / 并列独立反应 / 简单连续反应 / 多阶段强依赖反应链 / 竞争或副反应 / 条件改变导致方向或产物变化。
state_count：1个 / 2个 / 3个及以上。状态可指不同反应阶段、平衡状态、滴定区间、加入量区间、价态或流程节点，但普通并列物质不自动算多个状态。
process_state_relation：单一关系 / 状态相互独立 / 显性顺序衔接 / 前后状态强依赖 / 连续变化伴随平衡或边界。
constraint_structure：无约束 / 单一约束 / 多约束但相互独立 / 多约束联合筛选。
subquestion_dependency：无多问 / 相互独立 / 后问依赖前问。后问依赖前问不仅指直接引用前一问答案；只要后问必须基于前面已确定的反应关系、物种状态、实验结论、参数或边界条件继续建模，即为后问依赖前问。
shared_model_across_subquestions：true / false。共同使用一个普通方程式、同一章节名称或相同生活背景不足以判定共享复杂模型。
model_explicitness：模型完全显性 / 半隐含模型 / 隐含模型 / 需要自主建模。
model_relation：单一模型 / 同一模型多状态 / 模型切换 / 多模型或多平衡耦合。
reasoning_chain：直接判断 / 简单因果 / 多层因果 / 逆向推理或条件筛选。
hidden_conditions：无 / 单个隐含条件 / 多个隐含条件。
critical_condition：无临界 / 显性临界或过量条件 / 需要推导临界 / 隐含临界或过量条件。
classification_discussion：无 / 2类讨论 / 3类讨论 / 4类及以上。只有不同类别需要不同反应模型、约束或结果时才计数。
variable_relation：无变量关系 / 简单正反比 / 函数或图像关系 / 分段或非线性关系 / 多变量耦合。

chemistry_methods：从以下值选择零个或多个；没有则输出 []：

================================================================================
三、基于可观察 features 的原始正确率判定
================================================================================

只使用第二部分的可观察 features 与题目实际任务估分。可以根据 features 概括局部模型、完整任务和任务关系，但不得把这些概括简化为固定等级后直接对应习惯分数；任何正确率都必须回到具体 features 与完整作答稳定性说明。

### 估分前的三项 features 检查

1. **局部模型检查：**结合 knowledge_depth 和 model_explicitness，判断单个任务是教材直接结论、显性标准模型，还是需要模型转换、非显性关系或迁移；这只解释单个任务的可进入性，不能单独给出高分或低分。
2. **完整任务检查：**结合 step_count、state_count、knowledge_scope、calculation_complexity、experiment_requirement、synthesis_route 和 separation_purification，检查完成全部必要任务是否存在累计负担。不得只看最简单或最难的一步；也不得把步数、物质数量或小问数量本身作为降分理由。
3. **任务关系检查：**结合 subquestion_dependency、shared_model_across_subquestions 和 process_state_relation，检查各任务是可独立建模、共享同一复杂体系，还是必须以前序关系、物种状态、实验结论、参数或边界条件继续作答。答案不直接复用不等于共享模型不存在。

三项检查只用于组织 features 事实和 reason，不输出为新字段，不形成“低/中/高”等难度标签，也不对应任何固定分数。原始正确率评估的是普通考生完整完成全部必要任务的概率，不是完成其中最熟悉、最简单或最容易获得部分分的一步。不要用题型、选项数量、题干长度、物质名称多少或单个 feature 单独定档。

### 四个边界与五个原始正确率区间

目标学生群体是已经完成对应高中化学教学内容、参加普通高考的全体考生，不是竞赛生、重点班学生，也不是尚未学习该内容的学生。

第一阶段固定使用 88、85、58、38 四条边界；不得使用 75、55、35 或其他旧标尺。先依次比较题目与四条边界，再根据与上下相邻边界的实际距离给出连续原始正确率。本节不输出档位、threshold_review 或边界布尔值。

3/4边界只依据题目中可观察、可复核的拔高结构证据判断，不要求先给某个任务贴“核心拔高任务”标签。题干长、物质多、选项多、背景陌生或任务不是一步教材事实，均不单独构成拔高结构证据；标准化学计量、单一平衡定量、标准电化学、常规无机推断和标准实验数据处理，也不因步骤多而自动进入38—57.5区间。

#### ≥88：基础直接且能够稳定完成

核心判定：基础直接且能够稳定完成。普通考生可以直接、稳定地完成整题；全部必要任务均可由单一教材事实或单一显性规则完成，没有关系建立、条件筛选、信息反推或联合计算。

典型结构：
- 单一教材事实、化学用语、基本性质、唯一标准操作或一步直接化学计量；
- 通常为1—2个有效决策，模型完全显性，不需要建立题干特有的新关系；
- 多个对象或选项只是同一规则的平行应用，失误不会沿后续任务传播。

区间内位置：越接近纯识记、直接读数或唯一规则，越靠近上部；仍需一次简单判断、规范书写或轻微计算时靠近下部。

相邻区间排除：若必须完成实质表征转换、筛选反应条件、建立物种/反应/定量关系或分别核验多个异质条件，不应给出≥88；应检查是否落入85—87.5或更低区间。

常见误判：单选题有四个选项不是降低分数的理由；反过来，“知识点基础”也不能掩盖题目中真实存在的第二次化学决策。

#### 85—87.5：熟悉模型下的少量判断

核心判定：熟悉模型下的少量判断。主要任务能在熟悉标准模型下稳定完成，但只存在一次轻量判断、转换或规范书写负担；不需要根据题干特有条件建立新的化学关系后再继续作答。

典型结构：
- 一次表征转换、规范书写、简单条件筛选、一个显性状态变化或少量独立基础判断；
- 反应、条件和路径基本显性，通常不需要长链推理、复杂参数范围或多模型切换；
- 普通选择题可能涉及多个物质，但各项最高负担仍是直接判断或简单因果。

区间内位置：模型完全显性、失分点单一时靠近上部；需要两三个常规判断、一次关系建立或多个同质核验时靠近下部。

相邻区间排除：纯教材结论且没有第二次关键决策时应检查是否达到≥88；若必须先建立题干特有的物种、反应或定量关系，再利用该关系得出结论，应检查是否落入58—84.5或更低区间。

常见误判：不能因选项涉及不同物质就自动降低分数，也不能因所用模型“课内熟悉”就忽略条件筛选和关系建立。

#### 58—84.5：可分解的常规综合

核心判定：课内常规综合。普通考生需要在清晰的课内模型中，完成有限的条件筛选、关系建立、标准计算、表征转换或多个常规判断；主要难度来自理解题意并正确衔接这些常规步骤。题目可以有多个知识点、选项或小问，但所有主要结构仍处于常规模型强度，且不存在第四档所列任何明确拔高结构证据，才属于本区间；“模型熟悉、步骤可展开”本身不足以作出3档判断。

典型结构：
- 通常包含3—5个有效化学决策、多个关联评分点或多个异质判断；
- 一个显性连续反应、标准化学计量、单一平衡定量、标准电化学模型、常规无机推断或标准实验数据处理；
- 需要条件筛选、关系建立、表征转换或计算衔接，但主要关系显性，且未达到第四档所列的信息反推、联合条件、复杂定量、反应/模型复杂化或高阶实验/路线任务的组合强度。

区间内位置：主要关系显性、任务可分别完成且失误不传播时靠近上部；条件更多、任务衔接更紧或关键判断影响后续步骤时靠近下部。

相邻区间排除：若只有一次轻量转换或少量基础判断，应检查是否达到85—87.5；若出现第四档所列任一明确拔高结构证据，即使模型熟悉、只有一个最终输出、任务可分段或局部错误不向多个小问传播，也不得保留在本区间，应进入38—57.5区间定位。若多个必要决策围绕同一反应体系、实验装置、平衡/工艺流程或统一参数展开，且共同造成普通考生完成不稳定，也应检查38—57.5区间；关键错误传播会加强4档证据，但不是进入4档的必要条件。reason 中一旦已说明明确拔高结构证据，就不得再同时写“可分解的常规综合”或给出58分及以上的原始正确率；任务彼此独立、可以分段作答或局部模型属于课内熟悉，只能用于排除5档，不能推翻4档判断。

常见误判：熟悉标准模型不等于基础题；多个独立任务仍会形成整题完成负担；一个显性连续反应也不自动构成拔高题。

#### 38—57.5：拔高综合且完成稳定性较低

核心判定：出现至少一类明确的拔高结构证据，或多个中等强度结构共同使普通考生难以稳定完成整题；但尚未形成第五档所要求的两个高阶阶段强耦合。任务可以分段完成、部分小问可以独立作答或局部模型可以是课内熟悉模型，这些均不否定本区间；关键错误传播会使本区间更靠近下部，但不是进入本区间的前提。

进入本区间的具体结构证据包括以下五类。均须按题目实际条件联合判断，不能仅凭单个关键词、题型或知识点名称成立：
- 信息反推：需要由图表、流程、谱图、实验现象或多载体资料反推出隐藏量、反应关系、物种状态或关键条件，并伴随多层因果或逆向筛选；
- 联合条件：需要在多个条件、边界、过量不足、适用范围或分类分支之间联合筛选，任一条件遗漏都会改变结论；
- 复杂定量：需要联立多个定量关系、处理守恒差量或混合关系、进行参数/范围判断，而非单一公式或常规顺序代入；
- 反应或模型复杂化：需要处理竞争/副反应、条件改变导致的反应方向或产物变化、模型切换、多模型或多平衡耦合，或多个状态之间的实质关联；
- 高阶实验、合成或分离任务：需要设计、比较、评价方案，分析误差或证据链，而非识别基础仪器、复述操作或处理标准数据。

典型结构：
- 上述任一类明确拔高结构证据即可进入本区间，例如复杂图像/实验信息反推、联合定量、实验方案评价、受限结构枚举或关键中间体结构推断；3—5个有效决策也可能满足，步数不是进入本区间的必要条件；
- 也可表现为6—8个有效决策、四个及以上前后关联反应、三个及以上关联状态或多个前后依赖小问；
- 明显模型切换、竞争反应、隐含过量不足、多守恒或多平衡耦合、多约束联合、较长计算链；
- 流程图、曲线或谱图反推隐藏量，或高阶实验、合成、分离方案任务。
- 若难点表现为整体拔高证据，必须是同一体系中的多个必要判断共同造成完成不稳定，而不是若干独立基础小问的简单累加。

区间内位置：拔高结构较少、任务仍能分段完成时靠近上部；依赖关系更紧、状态和约束更多、关键错误影响多个后续任务时靠近下部。

相邻区间排除：3—5步常规综合且主要链条显性、关键任务可分别建模时应检查是否落入58—84.5；只有形成至少两个相互依赖的高阶阶段、整题难以拆解时，才检查是否低于38。

常见误判：实验、工业流程或有机合成不是自动降低分数的理由；但各问共享同一非常规装置、流程网络、反应路线或统一参数时，也不能拆成若干普通小问后高估正确率。

#### ＜38：压轴级强耦合任务网络

核心判定：至少两个第四档拔高结构证据形成相互依赖的高阶阶段。关键中间判断错误会连续影响后续多个评分点，整题不能拆成若干独立的普通综合任务。后一阶段对前一阶段的依赖，既可以是直接使用前一问答案，也可以是必须基于前面确定的反应关系、物种状态、实验结论、路线中间体、参数或边界条件继续作答。不能因为题目局部有基础小问、每个阶段使用课内模型，或前后小问不直接抄用答案，就把这种强耦合网络保留在38分及以上。

典型结构：
- 存在多阶段连续失分或强依赖任务链；前一高阶阶段先确定反应关系、物种状态、实验结论、路线中间体、参数或边界条件，后一高阶阶段必须以此继续建模；9步以上是常见表现，但不是进入本区间的必要条件；
- 复杂竞争反应、多模型或多平衡耦合、多状态强依赖、联合约束、复杂分类或隐含临界条件；
- 复杂参数范围与高阶实验、合成或分离设计形成连续的建模、计算和评价网络。

区间内位置：仍能识别主要模型、部分阶段可独立得分时靠近上部；入口判断高度隐蔽、多个高阶阶段强耦合且错误广泛传播时靠近下部。

相邻区间排除：只有拔高结构确实可以分别完成、彼此不共享决定后续作答的关系或中间结果时，或只有一类拔高结构证据加若干常规任务，才应保留在38—57.5区间或更高区间。存在基础小问、局部步骤可得分或部分阶段属于熟悉模型，均不能单独排除＜38区间。

常见误判：物质多、方程式多、计算繁琐、有机合成或单个高阶关键词，都不足以单独支持本区间。

四、区间内具体分数定位与程序乘数

### 1. 按相邻边界距离给出连续分数

确定题目位于哪两个相邻边界之间后，比较五方面证据：有效决策负担、任务关系、模型与条件显性度、信息转换与运算、失分传播与整题完成。模型更显性、决策更少、任务可独立完成且失分局部时，应更接近较高边界；决策链更长、任务依赖更强、信息转换更多或关键错误会向后传播时，应更接近较低边界。

不得先选取边界值、整数中点或任何示例值作为模板分数。结构相近的题可以同分，但只有上述五方面证据也相近时才合理；不得为了制造差异加入随机小数。一般易错、常规运算繁琐只能在相邻小范围内微调，不得单独将正确率压过一个主边界。

reason 必须用2—4句说明：构成主解题链的具体 features 与有效化学决策；完整任务是否存在累计负担、共享模型或前后依赖；为什么排除上一个更高正确率区间；为什么排除下一个更低正确率区间；以及该原始正确率的依据。原始正确率低于58时，必须指出至少一类具体拔高结构证据，或明确说明形成整体拔高证据的任务关系、状态/约束、信息反推和错误传播；原始正确率低于38时，必须分别指出两个相互依赖的拔高结构证据，以及后一阶段依赖前一阶段的关系、状态、参数或中间结果。不要输出额外的定位字段。

### 2. 原始正确率与高难特征乘数的职责边界

- 模型输出的 predicted_accuracy 是乘数处理前的原始正确率，必须包含题目中每个普通特征自身造成的解题负担。
- 不得因为程序可能识别出3类或4类高难特征，就在原始正确率中额外施加一次组合惩罚。
- 高难特征各自造成的普通难度应体现在原始正确率中；多个高难特征同时出现时的0.85或0.70乘数只由程序计算。
- 没有触发程序定义的高难特征，只表示乘数为1.0，不表示题目必然简单。

程序对原始正确率施加乘数后，按以下唯一标准映射最终难度档位：

| 乘数后正确率 | 最终档位 |
| --- | --- |
| ≥88 | 难度1档 |
| 85—87.5 | 难度2档 |
| 58—84.5 | 难度3档 |
| 38—57.5 | 难度4档 |
| ＜38 | 难度5档 |

上述表只说明程序对乘数后正确率的最终映射；模型仍只输出乘数前的连续原始 predicted_accuracy，不输出档位，也不为命中某个最终档位而反向调整 features 或原始正确率。

### 3. 输出前正确率自检

- 普通单选、多选和组合选项不得被当作多个独立必答任务机械相乘。
- 多个异质输出、共享模型或前后依赖，必须通过第二部分的 subquestion_dependency、shared_model_across_subquestions、process_state_relation 等 features 如实体现；不能只因有四个选项虚构多个任务。
- 题目长、图多、出现陌生物质、化学式复杂、反应多或计算量大，均不能单独降低正确率。
- 若使用课内标准模型但存在长链、多状态、多问依赖、共享复杂流程或联合约束，必须依据这些 features 的实际组合估分，不能以“反应常规”作为高分理由。
- 不得仅以“课内熟悉”或“各问可独立写出答案”作为高分理由；若 features 已显示深层关系、状态、信息转换、联合条件或共享体系，reason 必须说明这些事实为何不足以进入相邻较低正确率区间。
