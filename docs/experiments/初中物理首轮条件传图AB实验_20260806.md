# 初中物理首轮条件传图 A/B 实验

## 目的

当前生产冻结版在 recent3years 教师复核 500 题上达到 481/500（96.20%）默认接受率，19 道异常全部低估一档，且全部属于带图、图像、装置或空间关系题。现有 Prompt 和后处理已经覆盖这些结构，但文本输入可能使 Lite 低估真实决策链。

本实验只验证一个变量：首轮请求是否附加必要题图。正式 Prompt、模型、温度、后处理、输入题目和并发参数均保持不变。

## 实验设计

为避免 Lite 固定 temperature=1 带来的无关波动，不重新调用全部 500 题：

1. 以教师看到的 500 题原始模型结果作为固定基线；
2. 用 `auto` 路由离线选出视觉结构可能影响定档的题；
3. 对同一子集分别运行一次 `off`（文字对照）和一次 `auto`（条件传图）；
4. 未命中的题直接复用固定基线；
5. 比较 `auto` 相对同批 `off` 的改对、改错和净增正确数。

`off` 是默认值，因此当前生产冻结版行为不会改变。`auto` 不把“有图片”作为难度证据，只补充：

- 曲线、波形、轨迹和坐标关系；
- 电路拓扑、敏感元件和控制连接；
- 几何、光路、滑轮、弹簧和浮沉状态；
- 多图/多面板对应关系；
- 装置结构与材料新关系的联合建模；
- 以图片承载的多个选项。

文字已完整发送时优先原始题图，不重复发送 `/image/externalized/` 整页截图。每题默认最多发送 6 张图。

## 离线路由基线

在当前 500 题上：

- 500 道总题数；
- 354 道有可用图片 URL；
- `auto` 路由命中 280 道（56.0%）；
- 19 道教师异常中命中 15 道（78.95%）。

未命中的 4 道中，1 道题库没有可用图片 URL；另外 3 道的图片主要是背景/示意，错误更可能来自任务链计数而非视觉缺失。路由不为追求当前错题召回而加入题目专属关键词。

## 成功标准

首先看同一子集的 `auto` 与 `off` 配对结果，而不是只与历史基线比较：

- 必须满足 `auto_improved > auto_worsened`；
- 不得产生严重偏差；
- 无图或未路由题保持固定基线，不参与随机重跑；
- 若单次仅净增 1—2 题，视为证据不足，再重复一次同样的配对实验；
- 只有两次配对均为正净收益，且没有集中误伤某一档，才考虑把 `auto` 作为生产候选。

## 运行流程

准备实验子集：

```bash
python tools/physics_first_pass_image_ab.py prepare \
  --baseline outputs/visualizations/lite_physics_recent3years_1000_visualized500.jsonl \
  --output data/samples/physics_recent3years_teacher500_image_auto_subset.jsonl
```

随后对同一子集分别以 `--image-mode off` 和 `--image-mode auto` 运行首轮评级。最后使用：

```bash
python tools/physics_first_pass_image_ab.py evaluate \
  --baseline outputs/visualizations/lite_physics_recent3years_1000_visualized500.jsonl \
  --control outputs/model_runs/lite_physics_recent3years_teacher500_image_off.jsonl \
  --candidate outputs/model_runs/lite_physics_recent3years_teacher500_image_auto.jsonl \
  --annotations data/labeled/physics_difficulty_human_annotations_recent3years_500.jsonl \
  --output outputs/metrics/lite_physics_recent3years_teacher500_image_ab.json
```

正式结论以报告中的 `candidate_image_vs_control_text_only` 为准。
