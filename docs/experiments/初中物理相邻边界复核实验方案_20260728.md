# 初中物理相邻边界复核实验方案

## 目标

冻结第一阶段 Prompt 与后处理定档逻辑，只解决两个独立问题：

1. 最终等级的 `why_not_lower`、`why_not_higher` 必须只比较相邻档；
2. 用第二次 API 对高风险题做“二选一”的相邻边界复核，验证能否提高严格准确率和可接受率。

旧版自由五档 Agent 不再参与生产候选。历史实验已经表明，第二个模型自由重评五档时容易重复首轮偏差或引入更多错误。

## Pipeline

```text
冻结首轮评级
  -> 冻结后处理
  -> 最终相邻解释强制同步
  -> 确定性风险路由
  -> 选择唯一相邻边界
  -> 条件图片路由
  -> Lite 二选一证据复核
  -> 高置信写回门控
  -> 默认只审计、不改档
```

第二阶段看不到任何教师标签、GPT 裁定标签或来源 `difficulty`。它只能从指定的两个相邻档中选择。

## 第一阶段解释一致性

无论模型原判是否被后处理修改，最终均执行：

- 送分题：只与基础题比较；
- 基础题：只与送分题、中等题比较；
- 中等题：只与基础题、拔高题比较；
- 拔高题：只与中等题、压轴题比较；
- 压轴题：只与拔高题比较。

输出增加：

- `adjacent_lower_level`
- `adjacent_higher_level`
- `reasoning_consistency_repaired`（原解释明确引用了非相邻档时为 true）
- `adjacent_reasoning_normalized`（所有结果均为 true）

这一步不改变难度等级。

## 第二阶段路由

优先复核：

- 首轮发生相邻档后处理调整的题；
- 送分题、压轴题两个端点档；
- 最终等级与首轮 18 维特征明显冲突的题；
- 基础/中等、中等/拔高、拔高/压轴边界存在结构候选信号的题。

`--review-scope risk` 只调用风险题；`--review-scope all` 用于全量消融，不建议直接用于生产。

## 图片策略

默认 `--image-mode auto`。不会因为“如图”或存在图片 URL 就发送图片，只在以下情况发送：

- 多图或多面板共同推理；
- 曲线交点、斜率、非线性或图线反推；
- 多开关/电表/滑动变阻器/传感器共同构成的复杂电路拓扑；
- 空间、光路、受力作用点、力臂或规范作图依赖图形；
- 题干只有图像占位且解析未充分文字化；
- 首轮明确提取为“图像反推或外推”或“多图表综合”。

图片仅补足输入信息，不是升档信号。

## 自动写回门槛

默认 audit-only。即使复核模型提出改档，也只记录 `would_apply`。

只有显式传入 `--allow-writeback`，且同时满足以下条件，才允许相邻一档写回：

1. `boundary_status=明确归档`；
2. `confidence=高`；
3. 明确指出首轮结构判断错误；
4. 至少两条原文证据能在题干、选项、解析或小问中逐字核验；
5. 至少修正一个对边界有决定作用的 feature；
6. 若首轮发生后处理，必须指出实际规则及其前提为何不成立；
7. 最多调整一档。

## 推荐实验顺序

### A. 497 题：先跑 audit-only、不开图片

```bash
cd ~/prompt_test
source venv/bin/activate

mkdir -p outputs/model_runs outputs/logs outputs/metrics

nohup env \
  BOUNDARY_REVIEW_MODEL=doubao-seed-2.0-lite \
  BOUNDARY_REVIEW_TEMPERATURE=1 \
  python -u src/physics_difficulty_boundary_review.py \
    -i outputs/model_runs/lite_physics_d137510_497_run1.jsonl \
    -o outputs/model_runs/lite_physics_boundary_review_497_off.jsonl \
    -e outputs/model_runs/lite_physics_boundary_review_497_off_errors.jsonl \
    -p prompts/初中物理相邻边界复核提示词.txt \
    -c 20 -t 180 -r 3 \
    --review-scope risk \
    --image-mode off \
  > outputs/logs/lite_physics_boundary_review_497_off.log 2>&1 &
```

### B. 497 题：同一首轮结果，开启窄图片路由

```bash
nohup env \
  BOUNDARY_REVIEW_MODEL=doubao-seed-2.0-lite \
  BOUNDARY_REVIEW_TEMPERATURE=1 \
  python -u src/physics_difficulty_boundary_review.py \
    -i outputs/model_runs/lite_physics_d137510_497_run1.jsonl \
    -o outputs/model_runs/lite_physics_boundary_review_497_auto.jsonl \
    -e outputs/model_runs/lite_physics_boundary_review_497_auto_errors.jsonl \
    -p prompts/初中物理相邻边界复核提示词.txt \
    -c 20 -t 180 -r 3 \
    --review-scope risk \
    --image-mode auto \
  > outputs/logs/lite_physics_boundary_review_497_auto.log 2>&1 &
```

### C. 评测首轮、反事实写回和边界可接受率

```bash
python tests/boundary_review_regression.py \
  --csv data/labeled/physics_teacher_review_497_labels.csv \
  --evaluate outputs/model_runs/lite_physics_boundary_review_497_auto.jsonl \
  > outputs/metrics/lite_physics_boundary_review_497_auto.json
```

重点比较：

- `baseline.exact_match_rate`
- `counterfactual_high_confidence_writeback.exact_match_rate`
- `selected_label_acceptance_rate`
- `writeback_gate.improved / worsened`
- `adjacent_reasoning_violation_count`（应为 0）
- 图片开关下的净改善差异

## 上线判据

第二阶段先保持 audit-only。满足以下条件后才讨论自动写回：

- 高置信候选改档至少有稳定正收益；
- `improved / worsened` 明显大于 2；
- 严重偏差不增加；
- 图片 auto 相比 off 有净收益，而不是仅增加 token；
- 不同运行之间候选改档方向稳定。

若第二阶段仍无稳定净收益，则只上线“最终相邻解释同步”，保留冻结首轮等级。
