# 初中物理匿名边界多模型基准方案

## 目的

在不重跑首轮497题、不修改冻结 Prompt 和后处理的前提下，复用三次 Lite
结果，只让候选模型判断120道三次结果不一致的相邻边界题。实验要回答：

> 是否存在一个可用 API 模型，能把分歧题选择准确率从多数票的64.17%提高到
> 85.83%以上，从而让497题总体严格准确率达到90%？

## 模型

1. `doubao-seed-2.0-mini`
2. `doubao-seed-2.0-lite`
3. `doubao-seed-2.0-pro`
4. `deepseek-v4-pro`
5. `deepseek-v4-flash`
6. `glm-5.1`
7. `qwen3-max`
8. `glm-5.2`
9. `doubao-seed-2.1-pro`
10. `doubao-seed-2.1-turbo`

## 公平性控制

- 每个模型均采用 `balanced` 单裁判，不使用自身双裁判或仲裁；
- 输入题、候选边界、边界标准、动态 few-shot 和顺序种子完全相同；
- 当前题不会成为自己的 few-shot；
- Mini 显式使用 `temperature=0`；
- Lite 按服务端约束固定使用 `temperature=1`；
- 其他模型不主动发送温度，使用服务默认值；
- `api-mode=auto`：GLM 优先 Chat Completions，其他模型优先 Responses，
  首选协议失败后尝试另一协议；
- 每个模型全量前先执行一道真实分歧题预检；
- 每个模型结果文件只保存120道分歧题，377道一致题在汇总时按多数票恢复，
  以降低服务器磁盘占用；
- 模型按顺序运行，单模型失败只记录日志，不中断后续模型；
- 已完成模型自动复用，支持断点续跑。

## 基线与验收

- 三次 Lite 多数票：422/497，84.91%；
- 多数票在120道分歧题：77/120，64.17%；
- 达到总体90%需要：448/497；
- 候选裁判至少需要：103/120，85.83%；
- 候选理论上限：465/497，93.56%。

优先按分歧题准确率排序。低于64.17%的模型不具备写回价值；达到80%可进入
异构组合实验；达到85.83%才有资格作为90%目标的直接候选选择器。
