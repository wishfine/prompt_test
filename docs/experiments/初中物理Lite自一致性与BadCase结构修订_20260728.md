# 初中物理 Lite 自一致性与 BadCase 结构修订

## 1. 实验目标

只使用 `doubao-seed-2.0-lite`，分析 497 道教师复核题的错误共性，并验证多次 API 调用能否在不引入第二种模型和不使用模型裁判的前提下提高稳定性与准确率。

本轮不以 497 道题逐题增加关键词规则；Prompt 只修复可迁移的任务结构边界，现有单次后处理只保留历史上已验证为正收益的规则。

## 2. 数据与基线

- 教师复核标签：`data/labeled/physics_review_500_default.jsonl`
- 三次 Lite 结果：
  - `outputs/model_runs/lite_physics_teacherfeedback_497_run1.jsonl`
  - `outputs/model_runs/lite_physics_teacherfeedback_497_run2.jsonl`
  - `outputs/model_runs/lite_physics_teacherfeedback_497_run3.jsonl`

单次最终准确率分别为 81.89%、82.90%、83.10%，平均 82.63%。三次确定性多数票为 422/497，即 84.91%。

三次结果中：

- 377 题三次一致，一致部分准确率为 91.51%；
- 120 题存在分歧；
- 三次候选档位覆盖正确标签的理论上限为 93.56%；
- 既往 Lite、DeepSeek 等匿名裁判实验都低于多数票，说明“再让模型选择哪个答案正确”目前不可靠。

## 3. BadCase 共性

三次多数票仍有 75 道严格错误，主要转移为：

| 教师标签 → 多数预测 | 数量 |
|---|---:|
| 拔高题 → 中等题 | 18 |
| 基础题 → 送分题 | 17 |
| 送分题 → 基础题 | 11 |
| 基础题 → 中等题 | 9 |
| 中等题 → 拔高题 | 8 |
| 中等题 → 基础题 | 8 |
| 拔高题 → 压轴题 | 4 |

其中 32 道三次都错，属于优先修复的系统性错误。共性如下。

### 3.1 送分题与基础题

原 Prompt 对“直接检索束”的定义过窄，容易把不同选项对应不同教材事实、但每项都只需一步直接识别的概念题升为基础题。

反方向上，必须从图片恢复对象关系、完成规范操作、把生活过程转换为物理量变化，或自主选择规律的题目不能因步骤少降为送分题。

修订后的边界是：

- 多个选项可以对应不同教材事实；若每项都是一步直接识别，仍可判送分题；
- 识图重构、规范测量/作图、生活过程映射、规律选择或两次连续转换，至少进入基础题比较。

### 3.2 中等题与拔高题

原 Prompt 容易把“各问答案不直接复用”误解为“各问模型独立”，从而把共享复杂装置、材料新规律和参数网络的综合题拆散，只看一个局部小问。

修订后区分：

- 答案独立但模型共享；
- 模型真正独立。

新增“非平凡任务覆盖 W”只用于材料题、计算题、实验题和复杂装置多问，不用于普通概念选择题。满足多个非平凡任务共享题目特有信息，并包含关系推导、图表反推、双状态建式、跨模块模型、表达式建立或实验评价等结构时，必须进入拔高比较。

典型结构包括：

- 从图表归纳关系后推导表达式；
- 力/位移到电阻接入长度再到电学量的模型转换；
- 两个状态分别建式并消去未知参数；
- 材料中新规律的提取、迁移和表达式建立。

## 4. 后处理决策

### 4.1 不增加宽泛单次规则

对现有结果回放后，基于 `step_count`、图表、多状态等 feature 的宽泛中等→拔高规则均出现净误伤。原因是 18 个 features 粒度不足以可靠表达“答案独立但模型共享”和“决定性关系推导”。

因此：

- 不改写现有单次 `gpt56_hybrid` 后处理主规则；
- 不增加按关键词或 feature 数量直接升降档的规则；
- 继续保留已有正收益的中等→拔高、拔高→压轴结构校准与严重偏差保护。

### 4.2 新增确定性 Lite 自一致性聚合

新增 `src/physics_difficulty_lite_ensemble.py`：

1. 使用同一 Prompt、同一后处理和同一 Lite 模型独立运行 3 次；
2. 按 `question_id` 对最终等级多数表决；
3. 极少数全异情况按五档序数中位数决定；
4. 从投票获胜的某次结果中选取完整 features 和 reasoning；
5. 重新同步粗档与相邻档解释；
6. 保存每次等级、票数、输入文件哈希、代表运行和 token 合计。

该流程不调用裁判 API，不读取教师标签，不根据题目关键词改档。

现有三次结果回放得到 422/497（84.91%），与此前多数票统计完全一致。

## 5. 下一轮验收

使用修订 Prompt 独立运行 3 次，并同时报告：

- 每次严格准确率；
- 三次多数票准确率；
- 一档内比例、MAE、严重偏差；
- 各档 Precision、Recall、F1；
- 三次一致题数量及准确率；
- 75 道旧多数票错题中改对、改错和净增数量；
- 32 道旧三次一致错题中改对数量；
- 教师主动修改的 50 题与默认接受的 447 题分别准确率。

如果三次多数票稳定超过旧基线 84.91%，且默认接受题不明显下降，再考虑生产采用修订 Prompt。否则保留旧 Prompt，只上线确定性三次多数融合。

## 6. 首轮全量结果与二次修订

首轮修订 Prompt 的三次多数融合结果为 421/497，即 84.71%，比旧三次多数票 422/497 低 1 题。表面上总分基本不变，但逐题归因显示两类改动方向完全不同：

- 79 道题的新旧多数等级发生变化；
- 39 道改对，40 道改错；
- 教师主动修改的 46 道题由 13 道正确提高到 30 道，净增 17；
- 教师直接接受的 451 道题由 409 道正确降到 391 道，净减 18。

按具体转移统计：

| 新旧变化 | 改对 | 改错 | 净变化 |
|---|---:|---:|---:|
| 基础→送分 | 9 | 27 | -18 |
| 中等→拔高 | 11 | 8 | +3 |
| 中等→基础 | 5 | 3 | +2 |
| 基础→中等 | 5 | 1 | +4 |
| 送分→基础 | 4 | 0 | +4 |
| 压轴→拔高 | 3 | 1 | +2 |
| 拔高→中等 | 2 | 0 | +2 |

结论是：非平凡任务覆盖 W、双状态建式、表达式推导和模型共享等修订合计带来 17 道净收益；“不同教材事实的一步选项也普遍允许送分”单独造成 18 道净损失。

因此二次修订只撤回送分题的宽泛放松，恢复“直接检索束按同一回答规则定义”的保守边界；中高档结构修订全部保留。

### 6.1 送分一致性门控

三次 Lite 对送分/基础边界的分歧具有明显方向性。首轮修订结果中：

- 多数为送分、另一次为基础：19 题；
- 教师标签为基础：15 题；
- 教师标签为送分：4 题。

因此新增可消融参数：

```bash
--easy-requires-unanimity
```

开启后，仅当三次未一致判送分、且至少一次判基础时，把最终多数送分改为基础；其他四个边界仍严格使用多数票。

回放结果：

- 首轮修订 Prompt：421 → 432，净增 11，反事实准确率 86.92%；
- 旧 Prompt：422 → 423，净增 1，没有负收益。

该门控使用三次独立结果的分歧证据，不读取题干关键词、教师标签或裁判模型。下一轮应同时输出普通多数票与开启门控的结果，做零额外 API 成本的 A/B。

同时修正聚合结果的 raw 指标口径：聚合器现在单独计算三次
`difficulty_level_raw` 的多数等级并写入 `multi_call_raw_level`；
回归脚本优先使用该字段。此前聚合文件中的 `raw_evaluation`
只是代表运行携带的单次 raw 结果，不能解释为三次 raw 多数票。
